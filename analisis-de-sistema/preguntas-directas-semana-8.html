01 / 8 · Design token

¿Qué es un design token?

Ver respuesta y explicación

Respuesta A: Una variable con nombre para una decisión visual reutilizable

Un token centraliza valores como colores, tipografía, espaciado o radios y permite reutilizarlos consistentemente.

03 / 8 · Estado

¿Qué heurística exige informar al usuario qué está ocurriendo?

Ver respuesta y explicación

Respuesta A: Visibilidad del estado del sistema

La primera heurística busca que el usuario comprenda si una acción está en proceso, terminó o falló.

04 / 8 · POUR

¿Qué significa POUR?

Ver respuesta y explicación

Respuesta A: Perceptible, Operable, Comprensible y Robusto

POUR agrupa los criterios WCAG en cuatro principios de accesibilidad.

Base: Semana8-Presentacion-Analisis-Sistemas-II-037.pdf · página 18 del archivo PDF.

05 / 8 · Contraste

¿Cuál es el contraste mínimo AA indicado para texto normal?

Ver respuesta y explicación

Respuesta A: 4.5:1

El texto normal necesita al menos 4.5:1. El umbral de 3:1 corresponde al texto grande.

Base: Semana8-Presentacion-Analisis-Sistemas-II-037.pdf · página 21 del archivo PDF.

06 / 8 · Tamaño

¿Cuál es el tamaño mínimo de objetivo táctil presentado para WCAG 2.2?

Ver respuesta y explicación

Respuesta A: 24×24 px CSS

El material presenta 24×24 px CSS para 2.5.8 Target Size (Minimum), considerando sus excepciones al evaluar casos reales.

Base: Semana8-Presentacion-Analisis-Sistemas-II-037.pdf · página 20 del archivo PDF.

07 / 8 · Zoom

¿Qué exige el criterio 1.4.4 Texto redimensionable?

Ver respuesta y explicación

Respuesta A: Que el contenido siga siendo legible al aumentar el texto hasta 200 %

El contenido debe poder ampliarse hasta 200 % sin perder información o funcionalidad.

Base: Semana8-Presentacion-Analisis-Sistemas-II-037.pdf · página 21 del archivo PDF.

08 / 8 · Severidad

¿Qué valores utiliza la escala de severidad de Nielsen?

Ver respuesta y explicación

Respuesta A: De 0 a 4

La escala va de 0, no es problema, a 4, problema catastrófico.
